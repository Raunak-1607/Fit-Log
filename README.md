# Fit-Log

## Short Description
Fit-Log is a personalized fitness tracking application designed to help you log your daily workout routines, save your favorite exercises for later, and browse a comprehensive library of exercises with detailed instructions.

## Technologies Used
- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Toastify
- React Icons

## 5 Key Features of the Project
1. **Add Workouts to Today's Plan**: Easily queue up exercises for your current training session and keep track of your daily fitness goals.
2. **Save Workouts for Later**: Bookmark your favorite exercises so you can quickly access them in future workouts.
3. **Persistent Storage (LocalStorage)**: Your workout plan and saved exercises are safely stored directly in your browser, meaning you won't lose your data even if you refresh the page.
4. **Detailed Exercise Library**: Browse through a curated collection of workouts to see detailed instructions, targeted muscle groups, difficulty levels, and estimated calories burned.
5. **Interactive UI with Toast Notifications**: Enjoy a seamless and responsive user experience with instant, beautiful feedback via toast notifications when managing your workout plan.
